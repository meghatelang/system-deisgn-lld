# system-deisgn-lld

This repository contains **Low Level Design (LLD) questions and practical implementations** across frontend concepts.

## Included

- LLD questions and design notes
- Reusable UI components and patterns
  - Shimmer UI (Tailwind CSS)
  - Infinite Scroll
  - Accordion (open one accordion at a time)
  - Multi Accordion(open multiple accordions at a time)
  - Reddit Nested Comments
  - Image Slider (Carousel)
  - Autocomplete (Typeahead)
  - Youtube Live Stream Chat UI
